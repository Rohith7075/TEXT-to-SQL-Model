**# Text-to-SQL Model**



**A Text-to-SQL project focused on converting natural language questions into SQL queries, with support for \*\*PostgreSQL\*\* and \*\*Google BigQuery\*\*.**



**## Overview**



**The goal of this project is to make database interaction easier by allowing users to retrieve information using natural language instead of manually writing SQL queries.**



**The project focuses on working with different database environments and preparing the supporting data required for Text-to-SQL tasks.**



**## Key Objectives**



**- Convert natural language questions into SQL queries.**

**- Support PostgreSQL and Google BigQuery databases.**

**- Prepare and organize database-related datasets.**

**- Work with database schemas and query structures.**

**- Support cross-database Text-to-SQL experimentation.**



**## Database Support**



**| Database | Description |**

**|---|---|**

**| PostgreSQL | Relational database support |**

**| Google BigQuery | Cloud data warehouse support |**
